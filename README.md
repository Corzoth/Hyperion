# Hyperion
A project that branches from Chronos. Hyperion is an Ubuntu based home server for Chronos to connect back to. OPSEC is the main focus.


#Status: W.I.P

* Recently, got Hyperion online and runnning.
* Much work left to do, permenant encrypted listener must be setup
* Future plans to make the conenction between Hyperion and Chronos run through proxies for OPSEC

Currently, Hyperion is running on a temporary rig, that being an old office computer, so issues to do with hardware may arise in this initial testing phase, but soon a new dedicated server will be used for Hyperion.

Currently writing script for Chronos to connect to Hyperion, currently using socat for a more stable shell to be spawned between Chronos and Hyperion, plus for encryption.
